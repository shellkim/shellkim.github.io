# Shell — Sora Kim

김소라의 개인 홈페이지 첫 시안. HTML, CSS, JavaScript로 구성되어 별도의 빌드 없이 GitHub Pages에서 사용할 수 있습니다.

## 미리보기

이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1`을 실행하고 http://127.0.0.1:4173 에 접속합니다. 서버 없이 index.html을 열어도 기본 화면과 링크를 확인할 수 있습니다.

## 편집

- `index.html`: 공개 소개와 연락처
- `styles.css`: 색상, 타이포그래피, 반응형 배치
- `script.js`: 연도와 선택적인 등장 효과

외부 Google Fonts가 차단되면 시스템 글꼴로 표시됩니다. 서버 저장, 방문 추적, 쿠키는 사용하지 않습니다.

## 이후 확장

공개 승인을 받은 프로젝트·글·실험만 소개 다음에 개별 편집형 항목으로 추가합니다. 비공개 고객 프로젝트와 개인 프로젝트는 포함하지 않습니다. 콘텐츠가 쌓이면 별도의 기록 목록과 상세 페이지를 추가합니다.

공개 주소: https://shellkim.github.io/

GitHub Pages는 main 브랜치의 루트 폴더를 배포합니다. Projects는 현재 비활성 상태이며 실제 공개 작업이 생기면 다시 활성화할 수 있습니다.

## 프로젝트 공간

`projects.js`의 목록은 현재 비어 있으며 Showcase는 숨겨져 있습니다. 공개 승인된 실제 항목만 title, description, href, 선택적 image/imageAlt로 추가합니다. 항목은 개인 소개 뒤의 유한한 수평 공간에 나타납니다. 자동 이동은 화면 안에서만 작동하고, hover 시 감속, 직접 조작 후 정지합니다. 일반 세로 휠은 페이지 이동으로 유지합니다. 실제 콘텐츠 추가 시 넘침·스와이프·상세 페이지 복귀와 속도를 검증해야 합니다.
